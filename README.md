# AutoCRL (Auto Clash Royale League)

Этот юзерскрипт автоматически взаимодействует со стримом Clash Royale League, так что вы можете получать все награды, ничего не делая.

Скрипт переведен на Русский язык без сохранения оригинального шрифта (к сожалению).

Поддерживается:
- Cheers (нажатие на эмодзи во время матча)
- ~~Polls (выбор MVP после матча и т.д.)~~
- Quiz (автоматический выбор правильного ответа)
- Sliders (иногда появляются после матча с просьбой оценить его с помощью слайдера)
- Lootdrops (случайно появляющиеся сообщения, которые дают вам некоторое количество очков, если вы кликнете по ним в течение короткого времени)
- Predictions (отключено по умолчанию, автоматически делает предикты перед началом матча в соответствии с выбранной стратегией)

Работает на момент 8 ноября 2026.

![AutoCRL showcase](https://github.com/vadimkaxd/AutoCRL/raw/main/showcase.png)

## Быстрый старт

1. Установите менеджер юзерскриптов, например [Tampermonkey](https://www.tampermonkey.net/), [Violentmonkey](https://violentmonkey.github.io/) или другие.

2. Установите [AutoCRL](https://github.com/vadimkaxd/AutoCRL/raw/main/autocrl.user.js).

3. Откройте страницу трансляции на https://event.supercell.com/clashroyale/

4. Если в логах событий появилось сообщение "AutoCRL Загружен", значит скрипт работает. Теперь вы можете просто оставить вкладку открытой и позволить ему делать всю работу за вас.

## Известные/возможные проблемы
- Cheers не отправляются, если не выбран эмодзи (скрипт пытается выбрать его автоматически, но могут быть задержки).
- [Скрипт может не успеть отправить ответы, если на вашем компьютере неверно выставлено системное время](https://github.com/LaptopCat/AutoBSC/issues/6#issuecomment-5309955612).

## Оверлей
Оверлей состоит из двух секций:

### Данные
В этой секции отображается, сколько (предположительно*) пользователей подключено, и сколько предиктов было сделано на каждую команду.

> \* Я не знаю, насколько эти данные точны, но они приходят в сообщении чирса от сервера.

### Настройки
Позволяет настраивать скрипт через графический интерфейс. Названия пунктов полностью совпадают с меню скрипта:

- **Авточирс**: Автоматически отправляет чирсы (эмодзи по углам стрима) для получения 5 очков. *(Включено по умолчанию)*
- **Отвечать на опросы**: Автоматически отвечает на опросы (например, "Кто был MVP матча?") для получения 100 очков. *(Включено по умолчанию)*
- **Отвечать на викторины**: Автоматически выбирает правильные ответы в викторинах для получения 50 очков. *(Включено по умолчанию)*
- **Отвечать на слайдеры**: Автоматически двигает интерактивные ползунки для получения 2 очков. *(Включено по умолчанию)*
- **Собирать дропы**: Автоматически собирает случайно появляющиеся дропы для получения 10 очков. *(Включено по умолчанию)*
- **Автопредикт**: Автоматически делает предикты на матчи (10 очков, или 125, если прогноз верный). *(Отключено по умолчанию)*
    - **Стратегия предикта**: Логика выбора команды. Доступные варианты: *Только синие*, *Только красные*, *Случайно*, *За большинством*. По умолчанию — *За большинством*.
- **Логи в чат**: Выводит отчеты о действиях скрипта в ленту справа на экране. *(Включено по умолчанию)*
- **Динамические логи**: Показывает промежуточные статусы (например, "Проверяем кнопку..."). *(Включено по умолчанию)*
- **Без графики чирса**: Отключает анимацию чирсов для повышения производительности на слабых устройствах. *(Отключено по умолчанию)*
- **Отключить плеер**: Убирает загрузку YouTube-плеера. Полезно при плохом соединении. *(Отключено по умолчанию)*
